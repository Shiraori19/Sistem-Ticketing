XSS & HTML Attribute Breakout via json_encode / addslashes di Blade Inline Event Handlers
resources/views/public/index.blade.php:1340, admin/users/index.blade.php:160, admin/bidang_master/index.blade.php:151, admin/bidang/index.blade.php:259
Keamanan ▼
Deskripsi & Dampak

Penggunaan json_encode($var) atau addslashes($var) di dalam atribut HTML berkutip dua (seperti onclick="triggerPrintStruk({{ json_encode($strukData) }})", onclick="openEditModal({{ json_encode($u) }})", dan onclick="openReturnModal(..., '{{ addslashes($t->judul) }}')") menyebabkan karakter kutip ganda memecah batas atribut HTML (HTML attribute breakout). Karena data tersebut mencakup masukan pengguna (seperti judul kendala, nama lengkap pelapor, atau SKPD), karakter tanda kutip atau string kontrol memicu pembongkaran atribut dan eksekusi skrip berbahaya di peramban administrator maupun publik (DOM-based XSS).

Rekomendasi Tata Cara Perbaikan
  1. Hentikan penyisipan objek JSON mentah atau teks bebas ke dalam parameter fungsi inline event handler onclick.
  2. Manfaatkan HTML5 Data Attributes (data-*) yang secara otomatis di-escape secara aman oleh engine Blade.
  3. Pada fungsi JavaScript pemanggil, baca payload data objek secara aman dan bersih menggunakan API standar this.dataset dan JSON.parse().

Kerentanan Impersonasi Identitas NIP Pelapor & Ketiadaan Pra-Validasi Rumus BKN / OTP
app/Http/Requests/StoreTicketRequest.php:30, app/Http/Controllers/PublicTicketController.php:91-134
Keamanan ▼
Deskripsi & Dampak

Validasi NIP pada form pelaporan publik ASN saat ini hanya mengecek panjang 18 digit (size:18, regex:/^[0-9]{18}$/) tanpa memvalidasi rumus baku NIP ASN BKN (format tanggal lahir YYYYMMDD, TMT pengangkatan CPNS YYYYMM, gender 1/2, dan nomor urut). Selain itu, sistem mengizinkan siapa pun mengirim tiket tanpa pra-validasi kepemilikan NIP (tanpa OTP email dinas maupun WhatsApp). Siapa pun yang mengetahui NIP seorang pejabat/ASN Pemkot Cirebon dapat mencatut NIP tersebut, memasukkan nomor WhatsApp milik penyerang sendiri, dan membuat tiket palsu tanpa sepengetahuan pemilik NIP yang sah.

Rekomendasi Tata Cara Perbaikan
  1. Buat Custom Rule Laravel ValidNipBkn untuk memverifikasi digit tanggal lahir (umur 18-65 tahun), TMT pengangkatan CPNS, dan kode jenis kelamin.
  2. Wajibkan pengisian email kedinasan ASN (@cirebonkota.go.id) dan kirimkan kode OTP 6-digit via SMTP resmi Pemkot sebelum tiket masuk antrean verifikasi.
  3. Implementasikan mekanisme Silent Alert / Anti-Impersonation Dispute: jika NIP pernah melapor dengan nomor kontak A namun kini diajukan dengan nomor kontak B, sistem otomatis menembakkan notifikasi peringatan ke kontak lama.

Race Condition & File Isolation Collision pada Pembuatan Kode Tiket Baru
app/Http/Controllers/PublicTicketController.php:94-113, app/Services/TicketWorkflowService.php:51-68
Keamanan ▼
Deskripsi & Dampak

Pada PublicTicketController::store(), kode tiket dibuat di luar transaksi database sebelum berkas disimpan fisik ke disk: $kodeTiket = $this->workflowService->generateTicketCode(), lalu berkas disimpan ke tickets/{$kodeTiket}/. Penguncian transaksi database (pg_advisory_xact_lock) baru dieksekusi di dalam TicketWorkflowService::createTicket(). Jika dua pelapor menekan tombol kirim bersamaan pada milidetik yang sama, kedua request memperoleh calon kode tiket yang sama. Request kedua akan mendeteksi tabrakan di dalam createTicket() dan mengulang kode tiket ke nomor berikutnya, namun file lampirannya telah tersimpan di direktori fisik kode tiket pertama. Hal ini menyebabkan berkas lampiran tertukar atau menjadi berkas yatim (orphaned files).

Rekomendasi Tata Cara Perbaikan
  1. Simpan berkas lampiran yang diunggah sementara ke direktori staging acak berbasis UUID unik (tickets/staging/{uuid}/).
  2. Jalankan createTicket() di dalam database transaction dengan advisory lock untuk memastikan alokasi kode tiket permanen yang bebas konflik.
  3. Setelah kode tiket dipastikan unik dan tersimpan, pindahkan berkas dari direktori staging ke direktori definitif tickets/{kode_tiket}/.

Port Administrasi 8443 Terekspos ke Seluruh Antarmuka Publik (0.0.0.0)
docker-compose.yml:35
Infrastruktur ▼
Deskripsi & Dampak

Deklarasi port pemetaan Nginx di orkestrasi kontainer mencantumkan - "8443:8443" tanpa pembatasan binding IP host (default: 0.0.0.0:8443). Berdasarkan arsitektur Nginx, port 8443 melayani portal internal petugas (admin-ticketing.cirebonkota.go.id) sebagai isolasi pengganti VPN. Rekomendasi Tata Cara Perbaikan

  2. Tambahkan aturan firewall Nginx (allow <internal-ip>; deny all;) pada server block port 8443 di docker/nginx/default.conf.

Deskripsi & Dampak

Penomoran urut tiket bulanan dihitung dengan membaca MAX(CAST(RIGHT(kode_tiket, 4) AS INTEGER)) dari kolom string dengan pola LIKE 'TIK-YYYYMM-%'. Walaupun telah dilindungi pg_advisory_xact_lock, kueri pemindaian agregat pada substring kolom teks akan melambat saat volume data tiket bulanan mencapai puluhan ribu, berpotensi menimbulkan antrean kunci transaksi (lock wait timeout).

Rekomendasi Tata Cara Perbaikan
  1. Manfaatkan PostgreSQL Sequence terdedikasi per periode bulanan (misal CREATE SEQUENCE IF NOT EXISTS ticket_seq_YYYYMM) yang dieksekusi secara instan (O(1)) tanpa membaca tabel tickets.
